# 🎙 VoiceScribe

**リアルタイム文字起こし & 翻訳アプリ**

音声をリアルタイムで文字起こしし、日本語↔英語に自動翻訳するWebアプリです。  
インストール不要・登録不要・完全無料でご利用いただけます。

---

## 🌐 アプリURL

**https://fkd-streamlit.github.io/voicescribe/**

---

## ✨ 機能

- 🎤 リアルタイム音声認識（話しながら文字起こし）
- 🌍 日本語 → 英語 / 英語 → 日本語 の自動翻訳
- ⚡ 翻訳エンジンを自動選択（MyMemory / Lingva / LibreTranslate）
- 📋 文字起こし結果の画面表示・クリア機能
- 💰 完全無料・APIキー不要

---

## 🚀 使い方

1. **ChromeブラウザでURLを開く**
2. **マイクボタンをクリック** → ブラウザのマイク許可を「許可」
3. **話すと自動で文字起こし＆翻訳**が表示されます
4. 停止したい場合はマイクボタンを再度クリック

---

## ⚙️ 動作環境

| 項目 | 内容 |
|------|------|
| 推奨ブラウザ | Google Chrome |
| 音声認識 | Web Speech API（ブラウザ標準機能） |
| 翻訳 | MyMemory / Lingva / LibreTranslate（無料） |
| 対応言語 | 日本語・英語 |

> ⚠️ Safari・Firefoxでは音声認識が動作しない場合があります。Chrome推奨です。
